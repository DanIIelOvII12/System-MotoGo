Children
Name Description
 carrito : Entity

Almacena el carrito de compras de cada cliente, permitiendo guardar temporalmente los productos seleccionados antes de realizar un pedido.

 carrito_detalle : Entity

Almacena los productos agregados al carrito de compras junto con la cantidad y valores calculados temporalmente antes de confirmar la compra.

 categoria_especifica : Entity

Almacena categorías específicas asociadas a una categoría general de productos para permitir una clasificación más detallada.

 categoria_producto : Entity

Almacena las categorías utilizadas para clasificar los productos publicados por las tiendas dentro de MotoGO.

 ciudad : Entity

Almacena las ciudades asociadas a los departamentos para gestionar las ubicaciones registradas en MotoGO.

 cliente : Entity

Almacena la información personal de los usuarios registrados en MotoGO. Un cliente puede realizar compras, registrar direcciones, crear tiendas y solicitar convertirse en repartidor o tienda.

 compatibilidad_producto : Entity

Permite relacionar los productos con los modelos de motocicleta para indicar qué repuestos o accesorios son compatibles con cada modelo.

 departamento : Entity

Almacena los departamentos utilizados para organizar la ubicación geográfica de las ciudades registradas en MotoGO.

 direccion : Entity

Almacena las direcciones registradas por los clientes para la entrega de pedidos y gestión de ubicaciones dentro de la plataforma MotoGO.

 factura : Entity

Almacena la información fiscal y comercial generada después de confirmar una compra, sirviendo como comprobante oficial de la transacción.

 marca_moto : Entity

Almacena las marcas de motocicletas registradas en MotoGO para facilitar la búsqueda y compatibilidad de repuestos.

 metodo_pago : Entity

Almacena los métodos de pago disponibles que pueden utilizar los clientes para realizar compras dentro de la plataforma.

 modelo_moto : Entity

Almacena los modelos de motocicletas asociados a una marca específica, permitiendo determinar la compatibilidad de los productos.

 pago : Entity

Almacena la información de los pagos realizados por los clientes para cancelar los pedidos generados dentro de MotoGO.

 pedido : Entity

Almacena la información general de las compras realizadas por los clientes dentro de MotoGO.

 producto : Entity

Almacena la información general de los productos disponibles en MotoGO. Representa el catálogo maestro de repuestos y accesorios para motocicletas.

 repartidor : Entity

Almacena la información de los clientes que solicitan convertirse en repartidores dentro de MotoGO, incluyendo los datos de su licencia de conducción y el estado de aprobación.

 rol : Entity

Almacena los roles disponibles dentro de la plataforma MotoGO, permitiendo identificar el tipo de participación de cada usuario en el sistema. Un rol puede estar asignado a múltiples usuarios.

 rol_usuario : Entity

Permite asociar los roles a los usuarios registrados en MotoGO. Un usuario puede tener uno o varios roles, y un rol puede estar asignado a múltiples usuarios.

 tienda : Entity

Almacena la información de las tiendas registradas en MotoGO que ofrecen productos para la venta dentro de la plataforma.

 tienda_categoria : Entity

Relaciona las tiendas registradas en MotoGO con las categorías de productos que ofrecen.

 tienda_producto : Entity

Almacena las publicaciones de productos realizadas por las tiendas, incluyendo precio, stock, garantía y disponibilidad.

 tipo_documento : Entity

Almacena los tipos de documentos permitidos dentro de MotoGO para la identificación de los clientes registrados en la plataforma.

 tipo_vehiculo : Entity

Almacena los tipos de vehículos permitidos para que los repartidores realicen entregas dentro de la plataforma MotoGO.

 usuario : Entity

Almacena las credenciales y datos de acceso de los usuarios registrados en MotoGO. Permite gestionar la autenticación, recuperación de contraseña y estado de activación de la cuenta.

 vehiculo : Entity

Almacena la información de los vehículos registrados por los repartidores para realizar entregas dentro de la plataforma MotoGO.
